# 视觉预期卡

用于选定粗方案后，用户在 Figma 出稿前一次性选择视觉预期；AI 复述并锁定后直接开始出稿。

## 输入

- 选定的粗方案
- 所在页面和现有 Figma 页面

产品目标、用户范围和核心交互已在上游确认，本文件不重复讨论。

## 流程

### 1. 找出视觉分歧点

只选择本次真正影响视觉判断的 2–3 个问题，例如：

- 要多显眼
- 看起来是什么角色
- 第一眼先看到什么
- 与同屏内容谁轻谁重
- 要增强被看见、被看懂还是被点击
- 不能像什么

### 2. 生成选择题

- **固定 3 题，一次性发完。** 不一轮一个地追问。
- 每题提供 A、B、C 三个有明确差异的选项。
- 每题一行题干 + 三行选项，全部保持简短。
- 使用清晰、规范的表达。
- 不询问具体颜色、字号、图标或组件。

用户用 `1A 2B 3C` 的格式一次回完。用户只回部分或直接给一句描述时，其余项按推断的默认值补齐，不再追问。

### 3. 输出视觉预期

将答案合并为 1–2 句话，只说明：

- 显眼程度
- 视觉角色
- 第一视觉焦点（如需要）
- 要避免的感受

输出后不再等待用户回复“确认”，立即进入视觉方案。复述仅用于让用户知道 AI 将按什么执行；用户如发现偏差可随时打断，AI 收到打断后停止当前执行并修正。

## 边界

- 不改变选定粗方案的交互路径。
- 不重新定义产品目标或业务规则。
- 不把视觉预期直接写成组件、颜色或布局方案。

# 图表选型

> 通用设计知识，用于填补 Shopee 规范未覆盖的部分。Shopee 设计系统提供了 4 个图表组件，但没有规定「什么时候用哪一种」，本文件补这一条。
>
> 知识来源：原 `ui-ux-pro-max` 的 `charts.csv`（25 种数据类型的选型规则），于 2026-08-09 收编并与 library 实际组件对齐。原 skill 已从流程中移除。
>
> **与 Shopee 规范冲突时以 Shopee 规范为准**：配色一律用 L1 token，不采用外部配色建议；实现库推荐不适用于 Figma 出稿。

## 一、先判断该不该用图

- 数据点少于 4 个 → 用 MetricsCard，不用图表。
- 用户需要读精确值而不是看趋势 → 用 Table。
- 类目超过 15 个 → 用 Table + 搜索/排序，不用柱状图。
- 只有一个数字 → 用 MetricsCard。

图表回答「趋势和比例」，表格回答「具体是多少」。两者需求同时存在时，图 + 可切换的数据表，而不是把图做复杂。

## 二、library 已有组件的选型

| 数据类型 | 用哪个 | 什么时候用 | **什么时候不要用** | 数据量 |
|---|---|---|---|---|
| 趋势随时间变化 | **`Chart/Line`** | 有时间轴，用户要看涨跌趋势或变化率 | 少于 4 个点（改 MetricsCard）；超过 6 条线（视觉噪音）；没有时间维度 | 建议单图 ≤ 6 系列 |
| 类目对比 | **`Chart/Bar`** | 按量级比较离散类目，排序本身就是结论 | 类目 > 15（改 Table）；数据有时间维度（改 Line）；表达占比（改堆叠条） | < 20 类目用竖向；20–50 用横向；> 50 改分页表格 |
| 部分与整体 | **`Chart/Donut`** | 类目 ≤ 5；有一个明显主导的部分；强调视觉比例而非精确值 | 类目 > 5；切片差异 < 5%（视觉上分不出）；用户需要精确值 | 最多 6 片，超过改 100% 堆叠条 |
| 多维度对比 | **`Chart/Radar`** | 多个对象在同一组固定属性上比较（如商品能力对比） | 轴 > 8（读不了）；需要精确比较数值（改分组柱状）；受众不熟悉雷达图 | 每图 2–3 个数据集，5–8 条轴 |

基于 `Chart/Line` 可扩展的两种：

- **预测**：历史 + 预测线，预测段需视觉区分（虚线 / 置信带）。历史窗口 30–90 天，预测长度不超过可见 x 轴的 30%。
- **异常标注**：在折线上把异常点作为独立图层标出，并在图旁给异常列表；不要只靠一个红点。

## 三、library 没有组件的情况

以下数据类型在 Shopee library 中**没有对应组件**：散点 / 气泡、热力图、地图、漏斗、仪表盘（Gauge / Bullet）、树图（Treemap）、桑基图、瀑布图、网络图、箱线图、K 线。

处理顺序：

1. **先换表达**：多数场景能用已有的 4 种图 + Table 表达。漏斗可用横向 Bar + 转化率标注；Gauge 可用 MetricsCard + Progress；Treemap 可用可折叠的 Table。
2. **确实需要**：按 [`../../Shopee设计系统/L5_检查项/Shopee-guideline检查项.md`](../../Shopee设计系统/L5_检查项/Shopee-guideline检查项.md) 的「未建组件降级规则」处理并登记，同时提组件需求。
3. **不要自画一个图表组件**当作库内组件交付。

## 四、无障碍要求（硬性）

图表的可读性不能只靠颜色——这是 [`通用视觉规范.md`](通用视觉规范.md) §五「不只依赖颜色传达状态」在图表上的具体化，也和 L1「文本对比度」一节相互配合。

| 图表 | 无障碍等级 | 必须提供的兜底 |
|---|---|---|
| `Chart/Bar` | 好 | 数值标签常驻可见 |
| `Chart/Line` | 较好 | 每条系列用不同线型（实线 / 虚线 / 点线），不只靠颜色区分；可切换的数据表带时间与数值 |
| `Chart/Radar` | 一般 | **必须同时提供分组柱状图或原始数据表** |
| `Chart/Donut` | **差** | **必须提供百分比数据表作为兜底**；切片超过 5 个一律改用 100% 堆叠条 |

`Chart/Donut` 的等级最低，是因为环形图本身难以精确比较、且高度依赖颜色。**在无障碍优先或需要精确值的场景不要用它。**

配色一律取 L1 语义色，多系列时用不同色相的第 6 阶，不自造中间色；系列超过可区分范围时减少系列数，而不是继续加色。

## 五、通用判断口径

- 图表的默认答案往往是「柱状图」或「表格」，不是更花哨的那个。选了非常规图型，要能说出它比柱状图/表格好在哪。
- 坐标轴从 0 开始，除非有明确理由并已标注。
- 一张图回答一个问题。需要回答两个问题就拆两张图。
- 图例、坐标轴标签、单位缺一不可；把单位塞进标题不算。
- 实时数据必须有暂停或时间窗控制，否则用户无法阅读。

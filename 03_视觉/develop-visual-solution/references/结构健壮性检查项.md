# 结构健壮性检查项

> 与平台无关的通用检查。这类问题 AI 具备判断知识但仍会犯，且自查可靠性高，是内圈最先能生效的部分。
>
> Shopee 平台相关检查见 [`../../Shopee设计系统/L5_检查项/Shopee-guideline检查项.md`](../../Shopee设计系统/L5_检查项/Shopee-guideline检查项.md)。

## 内容显示

- [ ] 无文字溢出容器
- [ ] 无元素重叠
- [ ] 长文本有截断策略（省略号 / 换行 / Tooltip），不无限撑开
- [ ] 无内容被挤压变形

## 布局成立性

- [ ] 内容量变化后布局仍成立：增加标签、计数、长业务名之后不错位
- [ ] 空内容时布局不塌陷
- [ ] 异步内容已预留空间，加载完成后不发生布局跳动
- [ ] 在目标宽度范围内无明显错位

## 状态完整性

- [ ] 默认态存在
- [ ] 空态存在
- [ ] 加载态存在
- [ ] 错误态存在
- [ ] 禁用态存在（如该场景涉及）

## 层级与可读性

- [ ] 同层级元素视觉权重一致
- [ ] 可点击元素与不可点击元素在视觉上可区分
- [ ] 前后景对比度足以阅读

---

## 判定说明

以上均为客观项，全部需通过，不设通过率。

不属于本文件的：视觉是否精致、层级是否合理、信息优先级是否正确。这些属于人评项，见 [`../../../00_总流程/QA执行方式.md`](../../../00_总流程/QA执行方式.md)。

## 类型汇总
徽标通常出现在标记对象的右上角或后方，徽标图形内展示信息的数量、信息类型或其他相关信息。

|名称&编号|类型|使用场景|
|:--|:--|:--|

|**数字徽标**|![123](https://drive.google.com/thumbnail?sz=w3000&id=1PCUVnJ9J2aTxjHW124plmgaPM-L-fshb =106x)|- 用于需要突出更新的内容数目时的场景。|

|**脉冲**|![123](https://drive.google.com/thumbnail?sz=w3000&id=1NBuAq4xjNwKvjPF6EMgtMZZpX5Hw0Bll =16x)|- 活动类/营销类/全新版块上线类。<br>**允许有hover交互**|

## 使用用法 
徽标通常出现在标记对象的右上角或右侧，徽标应当靠近标记对象，并且和其他内容区分开，避免造成混淆和歧义。
### 1. 徽标及小红点
:::: row
::: col :span="4"
**【使用规则】**
- 被标记对象为 icon 时，徽标需在右上角（#0～99: 实际数值，100～+∞：99+）；
- 被标记对象为Button时，徽标的中心与Button的右上角对齐。

:::
::: col :span="8"
![123](https://drive.google.com/thumbnail?sz=w3000&id=1Y-D_WvFxhtvsTfVG_UC77w-4AD1XQS8x =100%x)
:::
::::

### 2. 脉冲
:::: row
::: col :span="4"
**【使用规则】**
- 被标记对象为Button时，徽标的中心与Button的右上角对齐；
- 脉冲作为新功能提示时，鼠标Hover出现新功能引导；
- 运动过程：不透明度从1到0.10；尺寸从6px到16px。

:::
::: col :span="8"
![123](https://drive.google.com/thumbnail?sz=w3000&id=1VSIz7-ps8n3yh5NS88VskrLK_zz8GDgp =100%x)
:::
::::

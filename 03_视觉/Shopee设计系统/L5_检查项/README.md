## 维护规则

- 先修改规则来源，再同步检查项。
- 无法由 AI 独立验证的内容不进入客观检查。
- 未定义或无法读取的 Token 标记为“未验证”，不得判为通过。
- 检查项全部通过，不使用通过率。

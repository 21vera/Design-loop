## A 组件使用（源：L2）

- [ ] 只使用库内正式组件，或按下方「未建组件降级规则」处理并已登记
- [ ] 未出现自画的按钮、输入框、标签、弹窗、表格等伪组件
- [ ] 图标来自 Icon 库，未自画 SVG
- [ ] 所有组件显式设置了关键变体属性，未沿用默认变体
- [ ] 默认占位文案已替换为真实业务文案

## B Token 与样式（源：L1）

- [ ] **本轮已完整读取** [`../L1_原子变量/README.md`](../L1_原子变量/README.md) 与 Figma `✅ Design Token 设计令牌` 页（node `1:2`）——未读取则本组全部判不通过，产出作废重做，不逐条核验
- [ ] 实际产出中的每个取值都能在出图前建立的 Token 清单中找到
- [ ] 无裸色值、裸间距、裸字号、裸圆角、裸阴影
- [ ] 颜色引用 Tier 2 Alias（`colorText*` / `colorBg*` / `colorBorder*` / `colorFill*` / `colorPrimary*` 等）或 Tier 3 组件 token
- [ ] 未直接引用 Tier 1 Base 调色板（`Base/Orange/6`、`Base/Neutral/9` 等）
- [ ] **产出中不存在 `Shopee Tokens` 以外变量集合的引用**（例如 IDS 的 `4. Components`）。跨库引用的组件必须已全量重绑到 `Shopee Tokens`——此项可在 Figma 中逐个读取绑定来源核验，不靠自觉
- [ ] 间距取 Base 九档之一：`sizeXXS` 4 / `sizeXS` 8 / `sizeSM` 12 / `sizeMS` 16 / `size` 16 / `sizeMD` 20 / `sizeLG` 24 / `sizeXL` 32 / `sizeXXL` 48
- [ ] 圆角取 `borderRadiusXS` 2 / `borderRadiusSM` 4 / `borderRadius` 6 / `borderRadiusLG` 8 之一
- [ ] 字号取 6 档之一（12 / 14 / 16 / 18 / 20 / 24），行高使用配对值
- [ ] 文本优先使用 9 个命名文本样式（Heading/xl–xs、Body/medium–regular、Caption/medium–regular）
- [ ] 阴影整体套用 `boxShadow` / `boxShadowSecondary` Effect Style，未手写单层阴影
- [ ] hover / active / 浅底 / 边框 / 文字色使用该语义角色的既有变体（`colorPrimaryHover` 等），未用透明度或换色阶模拟
- [ ] 禁用态使用组件 Disabled 变体 + `colorTextDisabled` / `colorBgContainerDisabled`，未用透明度模拟
- [ ] 正文 / 标题 / 表格数据只用 `colorTextHeading` / `colorText` / `colorTextSecondary`
- [ ] 彩色文字用 `*Text` 变体而非主体色（`colorPrimary` 作正文色仅 3.66:1，不通过）
- [ ] Success / Warning 未仅靠彩色文字承载信息（其 `*Text` 变体仅 2.65:1 / 2.10:1），已配图标或状态文案
- [ ] 灰底区域内的链接改用 `colorInfoText`（`colorLink` 在 `colorBgLayout` 上仅 4.24:1）

> 完整 token 表见 [`../L1_原子变量/README.md`](../L1_原子变量/README.md)。数值与 Figma 冲突时以当前 Figma 为准。
>
> 「未直接引用 Tier 1 Base」一项在向设计负责人确认前记为**建议项**，其余为硬判定项。

## C 页面结构（源：L3）

- [ ] 先有骨架再填内容
- [ ] 有对应整页模板时已从模板起手（见 L2「整页模板与业务模块」与 L4）
- [ ] 列表页含：Header / Sidebar / Breadcrumb / PageHeader / Filter 或 Search / Toolbar（有批量操作时）/ ResultBar / Table / Pagination
- [ ] 表单页含：Header / Breadcrumb / Form / Button 组

> 列表页骨架中 **PageHeader 与 ResultBar 目前无通用库组件**，按「未建组件降级规则」处理；**Toolbar 已建**（componentKey `e6d43de7…`），不得再以「组件未建」为由省略。

## D 操作与状态（源：L3）

- [ ] 同一区域最多 1 个 Primary 按钮
- [ ] 同一区域最多 1 个 Loading
- [ ] 主操作在右，取消 / 返回在左
- [ ] 表单底部按钮左对齐，表格与弹窗按对应规则对齐
- [ ] 同区域按钮不超过 3 个，超出已收入 Dropdown
- [ ] 危险操作有二次确认
- [ ] 表单错误就近显示，整页错误用顶部 Alert 汇总
- [ ] 加载态使用 Spin / Skeleton，未用文字占位

## E 与现有页面的一致性（源：L4）

**先判定适用性**，再逐条核验：

- [ ] 已确认本次页面类型在 [`../L4_现有页面/README.md`](../L4_现有页面/README.md) 中是否有整页模板或拆解

**有整页模板时：**

- [ ] 已从模板起手，而不是从空画布按配方拼
- [ ] 模板中标注为「复制块」的区块，未被当作组件契约依据；重做部分已改用库内组件重新拼装

**有同类拆解时：**

- [ ] 骨架与拆解一致
- [ ] 相同交互的实现方式与拆解一致
- [ ] 未沿用拆解中标注为「历史问题，勿沿用」的做法

**两者都没有时（当前的表单页、详情页、弹层任务即属此类）：**

- [ ] 本组判为**不适用**，改按 L3 页面骨架配方核验 C 组
- [ ] 已在交付说明中写明「无同类页面实例可对齐」
- [ ] 已把该页面类型登记为 L4 待补拆解

> 判为「不适用」需要满足上面三条并留下登记，不是跳过。

## 未建组件降级规则

骨架需要某个组件、但 [`../L2_组件/组件索引.md`](../L2_组件/组件索引.md) 中该组件为 ⏳（库中未找到）时，按以下顺序处理。**这是通过条件，不是豁免条件**——按规则处理并登记后，对应检查项判为通过；未按规则处理才判为不通过。

⚠️ **本规则只适用于 B 组以外的层级。Token 层（B 组）没有降级路径**——L1 与 Design Token 页必须每轮完整读取，读不到就停止出图并报出原因，不允许"先出图后补读"或"用近似值顶替"。

### 触发条件（不满足就不许启用降级）

降级不是万能通行证。必须同时满足：

- **白名单内**：只有 [`../L2_组件/组件索引.md`](../L2_组件/组件索引.md) 中明确标为 ⏳ 的组件可以走降级——当前是 **ResultBar、通用 Tooltip、通用 PageHeader、Tree、Timeline、ProductSelector**。不在名单上的组件"我找不到"**不算缺口，算没找对**，必须回 Figma 重新确认，不得直接降级。
- **单页上限 3 处**。超过 3 处说明骨架选错或页面类型判断错，回 L3 重新定骨架，不许一路降级下去。

### 处理顺序

1. **先复核**：在 Figma 中确认组件确实不存在。L2 索引的「未找到」来自语义搜索，不是硬证据；组件其实已建却按未建处理，同样算不通过。
2. **组合已建组件**：优先用库内已建组件拼装（例如 ResultBar 用 Toolbar + Text + Dropdown 组合）。组合件必须全部使用库内组件实例和 Token，不得自画。
3. **跨库引用**：本库确无、但集团其他已启用库中有正式组件时（例如通用 Tooltip、通用 PageHeader 在 `🧱 IDS Component UI-Kit`），可引用，但——

   ⚠️ **必须把颜色、字号、行高、圆角、间距、阴影全部重绑到 `Shopee Tokens`，一个不留。** 外部库有自己的变量集合（IDS 用的是 `4. Components`），原样引用等于**从后门把一整套不受 L1 管辖的 token 搬进 Shopee 页面**——组件层降级一下，Token 层跟着被绕过，而且因为"确实绑了变量"，常规检查还查不出来。
   
   重绑不完的（结构依赖某个 Shopee 没有的档位）→ **不许用这个组件**，退回第 2 步组合，或直接阻塞。
   
   必须记录来源库名、componentKey 和重绑结果。

4. **最小自建**：前三步都不可行时，允许**用已建组件拼装 + L1 Token** 搭建最小结构，**仅限本次出稿**，不得作为事实标准扩散。
   
   ⚠️ **不得自画任何基础形状**——按钮、输入框、标签、弹窗、表格一律禁止自画（这本来就是 A 组红线）。"最小自建"指的是组合与布局，不是重新画组件。
5. **登记**：以上任一路径都必须在交付说明中写一行 `组件名｜缺失原因｜本次替代方式｜是否需要立项建设`，并同步到 L2 索引的「缺口」章节。

不允许的做法：因为组件未建就省略骨架中的该区域；用文字或裸形状占位；把降级实现说成库内组件。

# 键盘与鼠标交互规范

> L1–L5 此前完全没有这一层。做表单、表格、弹层和列表批量操作时需要。
>
> 来源：Shopee EDS 设计规范 `design/keyboard`（designer: Rokin Qiu）与 `design/mouse`，2026-08-09 接入 L3。原文档见 [`../_建设参考/旧版设计规范/`](../_建设参考/旧版设计规范/)。

## 一、键盘

目标是让用户不抬手离开键盘就能访问全部功能。

| 按键 | 规则 |
|---|---|
| **Tab** | 把可操作项识别为焦点，导航顺序**符合逻辑且可预测**。所有交互式控件都应可获得焦点；非交互式控件（如 Tag）不需要。顺序按布局、视觉、逻辑定义。**初始焦点放在最可能点击的第一个（或主要）操作上**；⚠️ 不要把「删除」「否」这类会带来负面结果的目标设为初始焦点 |
| **方向键** | 目标在单列用上下键；单行用左右键；多列用全部四个方向键。方向键只对一个窗口/页面生效。多列时与 Tab 配合可更快切换 |
| **空格** | 文本输入模式下输入一个空格字符；非文本输入模式下等同 PageDown，滑到下一屏 |
| **Enter** | 按焦点所在控件类型执行：命令控件（按钮、链接）执行其操作；显示控件（如时间选择器）打开/关闭；其他按业务上符合习惯的操作 |
| **ESC** | 退出当前操作状态——关闭弹窗、让激活的输入框失焦 |
| **Home / End** | 区域内无列表或网格时，滚动到区域顶部/底部（焦点不变）。在列表或网格中且有焦点时，把焦点移到第一个/最后一个元素并滚动到位 |
| **PageUp / PageDown** | 按视区高度整页滚动，直至区域顶部/底部 |

## 二、鼠标

| 动作 | 定义 | 适用场景 |
|---|---|---|
| **悬停** | 移入目标元素 | 显示更详细信息或指导内容，且无需提交操作——Tooltip、信息提示、操作提示 |
| **单击** | 按下左键松开，不移动 | 选中并激活目标，响应其主操作——跳转、弹出菜单 |
| **单击并按住** | 按下左键不松开 | 通常伴随移动，动态选择页面元素，如选中一段文字 |
| **右键单击** | 按下右键松开，不移动 | 全局命令或与选定目标关联的应用栏。⚠️ **浏览器中不建议自定义** |
| **双击** | 连续两次快速按下松开左键 | 第一次选择、第二次确认。⚠️ **浏览器页面中不建议使用** |
| **滚动** | 滚轮或拖动滚动条 | 窗口或指定区域内上下左右移动 |
| **拖动** | 按住左/中键移动对象 | 拖动窗口、图标、图片 |
| **拖放** | 拖动后在目标位置松开 | 把对象放到新位置，如拖入文件直接上传 |

## 三、出图检查

- [ ] 所有交互式控件可获得键盘焦点，焦点态可见
- [ ] Tab 顺序与视觉顺序一致，且可预测
- [ ] 初始焦点不是「删除」「否」这类破坏性或否定操作
- [ ] 弹窗、Drawer、下拉可用 ESC 关闭
- [ ] 列表或表格内的方向键行为已定义
- [ ] 没有依赖右键菜单或双击作为唯一入口（浏览器中不建议）
- [ ] 悬停才出现的信息不是完成任务的必需信息

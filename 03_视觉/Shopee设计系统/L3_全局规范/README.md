# L3 全局规范

多类型页面与卡片的框架规则，以及组件之间的组合方式。

不属于组件维度，因此单独成层。

## 入口

[`全局规范.md`](全局规范.md) —— **AI 出稿的第一份文件。**

## 内容来源

合并自原 `seller-center-spec.md` 的 §二 页面配方与 §四 页面级规则，以及 `通用体验规则草案.md`。两者内容此前大量重复，现已合并为单一文件。

原 spec 的组件索引部分移至 `../L2_组件/组件索引.md`。

## 缺口

**配方颗粒度不足。** 当前配方只到组件级（「列表页用 Filter + Table」），未指到确切变体（「`Header Type=WithBreadcrumb`」）。

已验证结论：首次出稿质量问题主要来自变体选择错误与骨架缺失，而非组件缺失。因此配方指到变体是提升还原度的主要杠杆。

参考 `../L4_现有页面/my-products.teardown.md` 的写法——该文件已达到指到确切变体的颗粒度，可作为其他页面类型配方的模板。

**页面类型不全。** 目前六类配方中只有列表页有对应的实例拆解，表单页、详情页、Dashboard 均无。

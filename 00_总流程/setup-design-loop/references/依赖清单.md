## 外部能力

| 能力 | 用途 | 验证标准 | AI 自动处理 | 仅本人操作 |
|---|---|---|---|---|
| Product Design 插件 | 每次生成、编辑、合成或更新设计图片与视觉稿 | Step 0 逐个探测 `ideate` / `image-to-code` / `audit` 并写入 Case 标记。**探测结果为"不可用"不算未通过**（非 Codex 环境的常态）| 发现、安装、启用、调用与失败诊断 | 平台安装确认或账号授权（如平台强制） |
| Figma 插件或 MCP | 读取现有页面，写入可交互原型 | 账号已授权，读写工具存在；提供 Step 1 链接后可访问目标文件 | 工具发现、安装、启用、连接发起、打开授权页、授权后复检与错误诊断 | 登录、OAuth 同意、文件或企业权限批准 |
| Mobbin MCP | 查找 screen 和 flow | 可分别完成最小 screen 与 flow 搜索并返回有效结果 | 工具发现、安装、服务器配置、连接发起、打开授权页、授权后复检与错误诊断 | 登录、OAuth 同意、订阅或企业权限批准 |
| **Python ≥ 3.10** | Agent Reach 的运行前置 | `python3 --version` 输出 ≥ 3.10 | 只能检测和给出安装命令 | **安装 Python（Homebrew / 官方安装包 / CLT），涉及系统级安装或管理员密码** |
| Agent Reach 运行时 | 补充市场证据和网页来源 | `agent-reach doctor --json` 可执行，通用搜索和网页阅读可用 | 按 [`安装说明.md`](../../../02_交互/agent-reach/安装说明.md) 校验已安装 CLI，配置、诊断和无需身份的 channel 修复 | 安装 Python；必需的账号登录、Cookie 授权或安全验证 |
| 本地浏览器或原型渲染能力 | 预览和检查粗 HTML 原型 | 能打开本地 HTML 并检查交互 | 浏览器发现、启动、预览与 QA | 系统首次启动或文件访问权限批准 |

Product Design、Figma 和 Mobbin 连接及 Agent Reach 运行时不能仅通过复制文件夹完成，必须在安装环境中验证。

AI 必须先自动完成“AI 自动处理”列的全部步骤。不得让用户手动搜索插件、运行命令或编辑连接配置；只有“仅本人操作”列的动作可以暂停并请求用户完成。

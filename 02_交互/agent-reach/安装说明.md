# Agent Reach 安装说明

Agent Reach 是 Step 2 市场调研的强制依赖。本目录包含 Skill 本体与安装指引。

- `SKILL.md` / `references/` —— Skill 本体，随 Design Loop 一起安装到 Skill 目录。
- 运行时 CLI 按下方指引从上游 GitHub 安装（本包不再内嵌 `runtime/` 源码，2026-08-10 起移出）。

## 前置条件（必须先满足）

**Python ≥ 3.10。** Agent Reach 是 Python 包，没有 Python 就装不上，这一步 AI 无法代劳。

macOS 默认**不带**可用的 Python：`/usr/bin/python3` 只是一个占位符，调用它只会弹出 Xcode Command Line Tools 的安装框。

检查当前机器：

```bash
python3 --version
```

- 输出 `Python 3.10` 或更高 → 可以继续安装。
- 输出 `Python 3.9.x` → 版本不够，按下面装新版。
- 报 `xcode-select: note: No developer tools were found` → 没有 Python，按下面装。

### 装 Python（三选一，推荐第一种）

```bash
# 1. Homebrew（推荐，同时能装 pipx 和后续 channel 依赖）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python pipx
pipx ensurepath
```

```bash
# 2. 官方安装包：https://www.python.org/downloads/macos/ 下载 3.12 安装
```

```bash
# 3. Xcode Command Line Tools（会弹 GUI 安装框，可能需要管理员密码）
xcode-select --install
```

> 第 3 种最省事，但它自带的 Python 通常是 3.9.x，**可能不满足 ≥3.10**。装完请先跑 `python3 --version` 确认；不够就改用前两种。

上述命令都需要用户本人执行（涉及系统级安装、GUI 弹窗或管理员密码），AI 不代为执行。

## 安装 Agent Reach

前置满足后，从上游 GitHub 项目安装（本包不再内嵌离线源）。**推荐用一键脚本**，已装则自动跳过：

```bash
# 一键安装（已装则跳过，未装则从上游装）
if command -v agent-reach >/dev/null 2>&1; then
  echo "agent-reach 已安装：$(command -v agent-reach)"
else
  pipx install git+https://github.com/agent-reach/agent-reach.git
fi
agent-reach doctor --json
```

> 若上游仓库路径有变，按 GitHub 上 `agent-reach` 官方仓库的 README 安装。没有 pipx 时：
>
> ```bash
> python3 -m pip install --user git+https://github.com/agent-reach/agent-reach.git
> ```
>
> 遇到 `externally-managed-environment` 报错，是 PEP 668 保护，不是 Agent Reach 的问题。改用 `pipx`，或先建 venv 再安装。

验证（**必须返回 JSON 且通用搜索、网页阅读可用**）：

```bash
agent-reach doctor --json
```

**最小可用配置**：Step 2 调研只需「通用搜索 + 网页阅读」两个 channel；社交、视频等 channel 按需启用，不阻塞。

## 上游工具

Agent Reach 只是路由器和健康检查器，实际抓取由上游工具完成。各 channel 依赖不同的 CLI：

| channel | 依赖 | 是否需登录 |
|---|---|---|
| 网页搜索 | `mcporter`（Exa） | 否 |
| 网页阅读 | `curl` + r.jina.ai | 否 |
| GitHub | `gh` | 需 `gh auth login` |
| YouTube 字幕 | `yt-dlp` | 否 |
| V2EX | `curl` | 否 |
| B站 | `bili-cli` | 否 |
| Twitter / Reddit / 小红书 / Facebook / Instagram | `opencli` 或各自 CLI | **需要登录态或 Cookie** |

安装细节见上游 GitHub 仓库的 docs。**Design Loop 的 Step 0 只要求通用搜索和网页阅读可用**；社交、视频等 channel 按本次研究实际需要再配置，未配置的标注为"未配置"，不阻塞流程。

## 没有 Python 时怎么办

Agent Reach 不可用时，Step 2 的市场调研**不得静默跳过**。按以下顺序处理：

1. 明确告诉用户：Agent Reach 未安装，缺少 Python ≥3.10，并给出上面的安装命令。
2. 用户暂不安装时，改用当前环境可用的联网能力（内置 WebSearch / WebFetch、浏览器工具、Mobbin MCP）完成调研，并在内部记录"证据来源受限"。
3. 在粗方案画板的研究借鉴点中，如实标注哪些结论来自受限来源。
4. 不得因为工具缺失就编造竞品行为、来源或数据。

## 更新

运行时 CLI 随上游 GitHub 项目更新：`pipx upgrade agent-reach` 或重新安装。Skill 本体由 Design Loop 包统一维护；上游 `agent_reach/skill/` 有大版本更新时，人工对照后决定是否覆盖本目录的 `SKILL.md` 和 `references/`。

> 本目录的 Skill 于 2026-08-09 与官方 v1.5.0 同步。此前包内为旧版：缺 finance（雪球/股票）分类与 `references/finance.md`、`mcporter` 命令语法过时、`yt-dlp` 缺 `--write-auto-sub`、缺 Twitter 与小红书的 Cookie 安全约束、缺 OpenCLI 适配器发现章节。`runtime/` 源码与 `SKILL_en.md` 于 2026-08-10 移出包（前者改由上游安装，后者与 `SKILL.md` 双份维护冗余）。
